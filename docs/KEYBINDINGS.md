All the muscle memory in one place. For a printable cheat sheet, see [QUICK_REFERENCE.md](../QUICK_REFERENCE.md).

## Aerospace (window management)

Uses `Ctrl+Shift` for international keyboard compatibility (DHH-inspired). Each app lands on its home workspace via `[[on-window-detected]]` rules, so a launcher only launches. Workspaces 8 and 9 are free; 10-12 are overflow reached by cycling.

The tables below are generated from `.config/aerospace/aerospace.toml` by `dotfiles keys --update` (CI fails if they drift). `dotfiles keys` shows the same list in fzf, and `Ctrl+Shift+;` then `K` opens it in a Ghostty window.

### Service mode (`Ctrl+Shift+;` first)

| Key | Action | AeroSpace command |
|-----|--------|-------------------|
| `Esc` | Reload config and return to main mode | `reload-config, mode main` |
| `R` | Flatten workspace tree (reset layout) | `flatten-workspace-tree, mode main` |
| `F` | Toggle floating / tiling for the focused window | `layout floating tiling, mode main` |
| `Backspace` | Close all windows but current | `close-all-windows-but-current, mode main` |
| `K` | Open this keybinding cheatsheet in Ghostty | `exec-and-forget open -na Ghostty --args -e ~/bin/dotfiles-keys, mode main` |
| `Ctrl+Alt+H` | Join with window left | `join-with left, mode main` |
| `Ctrl+Alt+J` | Join with window down | `join-with down, mode main` |
| `Ctrl+Alt+K` | Join with window up | `join-with up, mode main` |
| `Ctrl+Alt+L` | Join with window right | `join-with right, mode main` |
| `Down` | Volume down | `volume down` |
| `Up` | Volume up | `volume up` |
| `Shift+Down` | Mute | `volume set 0, mode main` |
