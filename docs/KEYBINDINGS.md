# Keybindings

All the muscle memory in one place. For a printable cheat sheet, see [QUICK_REFERENCE.md](../QUICK_REFERENCE.md).

## Aerospace (window management)

Uses `Ctrl+Shift` for international keyboard compatibility (DHH-inspired). Each app lands on its home workspace via `[[on-window-detected]]` rules, so a launcher only launches. Workspaces 8 and 9 are free; 10-12 are overflow reached by cycling.

The tables below are generated from `.config/aerospace/aerospace.toml` by `dotfiles keys --update` (CI fails if they drift). `dotfiles keys` shows the same list in fzf, and `Ctrl+Shift+;` then `K` opens it in a Ghostty window. The command's flags: `--update` rewrites the generated block here, `--check` exits 1 when it is stale (CI), `--lint` exits 1 on a chord bound twice in a mode, a binding without a description or a script the repo does not ship, `--markdown` and `--tsv` print the tables instead of the fzf list, and `--config <aerospace.toml>` / `--doc <KEYBINDINGS.md>` point at other files.

## Ghostty

Hand-written from the `keybind =` lines in `.config/ghostty/config`. Everything else is Ghostty's default.

| Key | Action | Ghostty action |
|-----|--------|----------------|
| `` Cmd+` `` | Toggle the quick terminal: a drop-down scratch terminal over whatever is on screen, bound globally so it works from any app (AeroSpace does not tile it) | `global:super+grave_accent=toggle_quick_terminal` |
| `Cmd+D` | New split to the right | `new_split:right` |
| `Cmd+Shift+D` | New split below | `new_split:down` |
| `Cmd+Shift+H` | Focus split left | `goto_split:left` |
| `Cmd+Shift+J` | Focus split below | `goto_split:bottom` |
| `Cmd+Shift+K` | Focus split above | `goto_split:top` |
| `Cmd+Shift+L` | Focus split right | `goto_split:right` |
| `Cmd+Up` | Jump to the previous prompt (shell integration) | `jump_to_prompt:-1` |
| `Cmd+Down` | Jump to the next prompt | `jump_to_prompt:1` |
| `Cmd+Shift+E` | Write the scrollback to a file and open it in `$EDITOR` | `write_scrollback_file:open` |

New windows and tabs inherit the working directory and font size of the current one, and closing a surface with no running process does not prompt.

## Zellij

`.config/zellij/config.kdl` keeps every Zellij default and overrides these in normal mode:

| Key | Action | Zellij action |
|-----|--------|---------------|
| `Ctrl+O` | Session mode (by default this chord opens pane mode; pane mode stays on `Ctrl+P`) | `SwitchToMode "Session"` |
| `Alt+H` / `Alt+L` | Focus pane left / right; at the edge of the tab, move to the previous / next tab | `MoveFocusOrTab "Left"` / `"Right"` |
| `Alt+J` / `Alt+K` | Focus pane down / up | `MoveFocus "Down"` / `"Up"` |

Defaults worth knowing: `Ctrl+G` locks (keys pass through to the program in the pane), `Ctrl+P` pane, `Ctrl+T` tab, `Ctrl+N` resize, `Ctrl+S` scroll, `Ctrl+Q` quits. The status bar lists the keys for whichever mode is active.

### Layouts and sessions (aliases in `.zshrc-terminal-enhancements`)

| Alias | Layout | Tabs |
|-------|--------|------|
| `zr` | Rails | editor, server (rails s + console), tests, terminal |
| `zp` | Phoenix | editor, server (phx.server + iex), tests, terminal |
| `zw` | Work | editor, server (two panes), terminal |

Sessions: `zn <name>` starts a named session, `za <name>` attaches, `zl` lists, `zk <name>` kills. Tabs: `zt` opens one, `zc` closes the current one.

## Customizing

- **Aerospace**: `.config/aerospace/aerospace.toml`, then `dotfiles keys --update` and `dotfiles keys --lint`
- **Ghostty**: `.config/ghostty/config` (`keybind =` lines), then `ghostty +validate-config`
- **Zellij**: `.config/zellij/config.kdl`
- **Neovim**: `.config/nvim/lua/plugins/*.lua`
