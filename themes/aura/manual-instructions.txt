  Manual Theme Steps: Aura Dark
══════════════════════════════════════════════════════

The following apps need manual theme selection.
Most are one-click installs — just follow the links!

──────────────────────────────────────────────────────
SLACK
──────────────────────────────────────────────────────
  1. Open Slack → Preferences → Themes
  2. Scroll to "Colors" section and click "Custom Theme"
  3. Paste this color string:
     #15141b,#121016,#3b334b,#61ffca,#3b334b,#adacae,#a277ff,#a277ff,#15141b,#edecee

──────────────────────────────────────────────────────
GOOGLE CHROME
──────────────────────────────────────────────────────
  Install from Chrome Web Store:
  https://chromewebstore.google.com/detail/aura-theme/ddipnaombfnagpagnpdkdinoekfhfjoh

──────────────────────────────────────────────────────
ZEN BROWSER
──────────────────────────────────────────────────────
  Zen is a Firefox fork, so the Firefox add-on installs directly:
  https://addons.mozilla.org/en-US/firefox/addon/aura-theme-v2/

  Then: Zen menu -> Add-ons and Themes -> Themes -> Enable "Aura"

──────────────────────────────────────────────────────
TELEGRAM
──────────────────────────────────────────────────────
  NOTE: two different Telegram apps exist on macOS with incompatible
  theme formats. You have "Telegram for macOS" (ru.keepcoder.Telegram),
  which CANNOT read .tdesktop-theme files -- those belong to Telegram
  Desktop (org.telegram.desktop). That is why the upstream Aura theme
  would not load.

  Use the .palette file instead:

  1. Telegram → Settings → Appearance
  2. Drag this file onto the Telegram window:
     ~/code/dotfiles/themes/aura/telegram/Aura Dark.palette
     (or use the theme import option in that panel)

  The palette was produced by exporting this client's own theme and
  replacing every colour with the Aura equivalent, so the key names are
  guaranteed to match what this version expects.

  The .tdesktop-theme file is kept alongside it for the day you install
  Telegram Desktop, where it works as-is.

──────────────────────────────────────────────────────
XCODE  (installed automatically)
──────────────────────────────────────────────────────
  The theme is copied to ~/Library/Developer/Xcode/UserData/
  FontAndColorThemes/ by apply-theme.sh. To activate it:

  Xcode → Settings → Themes → select "Aura Dark"

──────────────────────────────────────────────────────
OBSIDIAN
──────────────────────────────────────────────────────
  No official Aura port exists. Closest match:
  Settings → Appearance → Themes → Browse → search a dark theme
  (e.g. "Obsidianite" or "Primary"), then set Base color scheme: Dark
