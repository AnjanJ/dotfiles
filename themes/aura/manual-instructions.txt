  Manual Theme Steps: Aura Dark
══════════════════════════════════════════════════════

The following apps need manual theme selection.
Most are one-click installs — just follow the links!

──────────────────────────────────────────────────────
SLACK
──────────────────────────────────────────────────────
  1. Open Slack → Preferences → Themes
  2. Scroll to "Colors" section and click "Custom Theme"
  3. Paste this color string:
     #15141b,#121016,#3b334b,#61ffca,#3b334b,#adacae,#a277ff,#a277ff,#15141b,#edecee

──────────────────────────────────────────────────────
GOOGLE CHROME
──────────────────────────────────────────────────────
  Install from Chrome Web Store:
  https://chromewebstore.google.com/detail/aura-theme/ddipnaombfnagpagnpdkdinoekfhfjoh

──────────────────────────────────────────────────────
ZEN BROWSER
──────────────────────────────────────────────────────
  Zen is a Firefox fork, so the Firefox add-on installs directly:
  https://addons.mozilla.org/en-US/firefox/addon/aura-theme-v2/

  Then: Zen menu -> Add-ons and Themes -> Themes -> Enable "Aura"

──────────────────────────────────────────────────────
TELEGRAM
──────────────────────────────────────────────────────
  IMPORTANT: there are two different Telegram apps on macOS and they use
  different, incompatible theme formats.

  You have "Telegram for macOS" (ru.keepcoder.Telegram) -- the native
  Swift client. It CANNOT read .tdesktop-theme files; those belong to
  Telegram Desktop (org.telegram.desktop), a separate app. That is why
  "Choose from file" would not accept the upstream Aura theme.

  Two options:

  A. Use the built-in dark theme with an Aura accent (quickest):
     Settings → Appearance → choose the Night/Dark theme, then set the
     accent colour to #a277ff via the custom colour picker.

  B. Try the macOS palette shipped here:
     Settings → Appearance → drag aura-dark.palette onto the window, or
     look for an import/"New theme" option in that panel.
     File: ~/code/dotfiles/themes/aura/telegram/aura-dark.palette

     This client's import UI has changed across versions and it mainly
     uses *cloud* themes (shared via t.me links) rather than local files,
     so B may simply not be offered in your build. If it is not, use A --
     the accent colour is what carries the Aura look.

  The .tdesktop-theme file is kept alongside it for the day you install
  Telegram Desktop, where it works as-is.

──────────────────────────────────────────────────────
XCODE  (installed automatically)
──────────────────────────────────────────────────────
  The theme is copied to ~/Library/Developer/Xcode/UserData/
  FontAndColorThemes/ by apply-theme.sh. To activate it:

  Xcode → Settings → Themes → select "Aura Dark"

──────────────────────────────────────────────────────
OBSIDIAN
──────────────────────────────────────────────────────
  No official Aura port exists. Closest match:
  Settings → Appearance → Themes → Browse → search a dark theme
  (e.g. "Obsidianite" or "Primary"), then set Base color scheme: Dark
